# UI 리디자인 단계 정리 (U 단계, 2026-10-13 · U0 완료 2026-10-27, ADR 0004)

참고 그림: 사이드바 + 카드형 대시보드(라이트 테마, 창 약 1000×720). 그림의 "링크온" 화면을 ezBAK 기능에 대응시킨다.

## 사용자 결정 (2026-10-13)

| 항목 | 결정 |
|---|---|
| 툴킷 | CustomTkinter 를 바로 쓴다(두 방식 비교 시제품 생략) |
| 창 틀 | 기본 Windows 제목 표시줄 유지, 색만 맞춤(틀 없는 창 안 함) |
| 새 데이터 카드 (속도 그래프·마지막 백업·다음 예약) | U7 로 미룸. 홈은 지금 있는 정보로만 채움 |
| 대화상자 | 새 스타일로 바꿈(U6 포함) |

## 위험

- U4 가 제일 위험하다. CustomTkinter 위젯은 안에 캔버스를 품고 있어 창 구조 스냅샷이 크게 바뀌고, 테스트 도구의 트리 순회를 손봐야 할 수 있다.
- 그림에는 라이트만 있다. 다크 색상표는 U1 에서 따로 정한다.
- 글꼴: 그림은 Pretendard 계열. 같이 넣으면 exe 가 커지고 ctypes 등록이 필요하다. U1 에서 맑은 고딕·Segoe UI 와 함께 결정한다.
- 새 화면 문구는 번역 키 추가다. strings_en/ko 를 고치는 발주는 단독으로 돌리고, gui_snapshot translations 도 다시 만든다.

## 시작

사용자가 "U0·U1 진행해"라고 요청하면 시작한다. 그 전에는 착수하지 않는다.
