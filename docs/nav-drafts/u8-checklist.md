# U8 실기기 체크리스트 (2026-10-27, ui-plan §9 U8-4)

Windows 실기기에서 채운다. 클라우드 세션과 CI(windows-latest, 96 DPI)는 배율 100% 만 보므로 125·150%·모니터 이동은 여기서만 확인된다.
기준 커밋: U8-3(34402b9, DPI 켜짐) 이후. 결과 칸: ✅ 정상 / ❌ 문제(아래 "발견" 에 적기) / — 해당 없음.

## 0. 준비
- [ ] `python -m pip install -r requirements.txt` 뒤 `python ezBAK.py` 로 실행(관리자 재실행 창이 뜨면 허용)
- [ ] exe: `.\scripts\build_pyinstaller_script.ps1 -ScriptName ezBAK.py` → `ezBAK.exe` 실행(테마 JSON 누락 FileNotFoundError 없음, 아이콘 표시)
- [ ] 배율 바꾸기: 설정 → 디스플레이 → 배율. 바꾼 뒤 앱을 **다시 시작**한다(Tk pt 배율·tk_font 는 시작 때 한 번 정함)

## 1. 배율 × 테마 (메인 창)
설정이 없으면 다크로 시작한다(D4). 라이트는 설정 페이지에서 바꾸고 다시 시작.

| 확인 | 100% 다크 | 100% 라이트 | 125% 다크 | 125% 라이트 | 150% 다크 | 150% 라이트 |
|---|---|---|---|---|---|---|
| 창 1000×700(배율만큼 큼)·minsize, 제목 표시줄 색이 테마와 맞음 | | | | | | |
| 사이드바 8개·상태 칩 "대기"/"작업 중 n%" 잘림 없음 | | | | | | |
| 홈: 원형 백업 버튼·사용자 제목·필터 칩·지표 2·시스템 카드 | | | | | | |
| 백업·복원·예약·도구 페이지 버튼 글자 잘림 없음(버튼 3열) | | | | | | |
| 로그 페이지·홈의 Activity Log 글자 크기가 다른 글자와 비슷함 | | | | | | |
| 상단 사용자 콤보·하단 진행 막대·상태 줄 | | | | | | |
| 설정 페이지 소리 토글(캔버스)이 글자와 같은 비율 | | | | | | |

## 2. 대화상자 (150% 다크·라이트 각각, 다른 배율은 문제 있을 때만)
창 크기가 내용보다 작아 버튼이 잘리거나, 글자가 너무 작거나(tk 글꼴이 100% 에 머무름) 너무 크면 ❌.

| 대화상자 | 여는 법 | 다크 | 라이트 |
|---|---|---|---|
| Win11Dialog 정보·경고·오류 | 도구 → Check Space 등 | | |
| Win11Dialog 예/아니오(긴 문구) | 복원 → 덮어쓰기 경고 | | |
| 필터 관리 + 규칙 추가 + 도움말 | 백업 → Filters | | |
| 원본 선택 + 폴더 트리 행 높이 + 도움말 | 도구 → Copy Data | | |
| 예약 백업 + 도움말 | 예약 백업 → Schedule | | |
| NAS 연결·해제(명령 도움말 줄바꿈) | 도구 → Connect NAS / Disconnect | | |
| 복원 폴더 선택·교차 사용자 경고 | 복원 → Restore Data | | |
| F1 단축키 도움말(449×748 × 배율, 화면보다 크면 ❌) | F1 | | |

## 3. 한·영 문구 길이 (150%, 두 언어)
언어는 설정 페이지에서 바꾸고 다시 시작. 영어가 대개 더 길고, 한국어는 맑은 고딕 글자 폭이 넓다.

| 확인 | en | ko |
|---|---|---|
| 사이드바 "Scheduled Backup"/"예약 백업"(가장 긴 메뉴) | | |
| 페이지 안내 글 줄바꿈(백업·복원·예약·도구 카드) | | |
| 버튼: Backup Drivers·Restore Drivers·Connect NAS·Export Apps 와 한국어 대응 | | |
| 필터 대화상자 설명(name_desc·path_desc, 57~59자 폭)·filter_info_include | | |
| 예약 시간 오류 문구(invalid_time_format, 한국어 59자 폭) | | |
| 하단 주의 문구(notice_responsibility, 한국어 61자 폭 — 가장 김) | | |

## 4. 모니터 이동 (배율이 다른 모니터 2개가 있을 때만)
- [ ] 메인 창을 다른 배율 모니터로 옮기면 CTk 위젯은 다시 그려진다. tk 부분(로그 글자·진행 막대·콤보)은 시작 때 배율에 남는다 — 알려진 한계, 읽기 어려울 정도면 ❌
- [ ] 옮긴 뒤 대화상자를 열어도 오류 창·Tk 예외가 없음(대화상자는 tk.Toplevel 이라 CTk 배율 감시 대상이 아님)

## 5. 동작 한 바퀴 (150% 한 번)
- [ ] 백업(작은 사용자 폴더)·복원·공간 확인·복사가 끝까지 가고 진행률·상태 칩이 움직임
- [ ] 예약 작업 만들기 → 작업 스케줄러에서 확인 → 삭제
- [ ] Ctrl+1~9·F1·F5 등 단축키(설정 → 도움말 표와 같음)

## 6. U7 홈 데이터 카드 (100% 한 번, 150% 한 번)
- [ ] 시작 뒤 10초 안에 시스템 이름이 "불러오는 중..." 에서 실제 이름으로 바뀜
- [ ] 백업 한 번 뒤(10초 안) 마지막 백업 카드에 시각·사용자·"수동"·폴더 이름, 여유 공간 타일에 그 드라이브의 여유 공간
- [ ] 예약 백업을 하나 만들면 다음 예약 카드에 작업 이름과 다음 시각(매주는 일요일, 매월은 그 날짜)
- [ ] 백업·복사 중 복사 속도 카드에 MB/s 와 꺾은선이 움직이고, 끝나면 "실행 중인 복사 없음"
- [ ] `%APPDATA%\ezBAK\state.json` 에 last_backup 이 생기고 settings.json 은 그대로
