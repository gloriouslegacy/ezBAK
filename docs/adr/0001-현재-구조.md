### 호출 경로
- GUI 백업(S1): `start_backup_thread` → 작업 로그 열기(`open_log_file`) → 스레드 `run_backup` → `is_hidden_safe` + `copy_file_with_progress_safe` → `backup_browser_bookmarks` → `_cleanup_old_backups`·`_cleanup_old_logs` → `message_queue` 튜플 → `process_queue`(`after` 폴링, 13종 task 문자열).
- Headless·스케줄(S3): `__main__` → `_run_headless_if_requested` → (`--schedule-config` JSON 또는 `--user/--dest`) → `core_run_backup` → stdout `print`.
- 복원(S2): `start_restore_thread` → `run_restore` — 사용자 확인이 필요하면 큐에 `show_cross_user_warning`/`select_folder` 를 넣고 `hasattr(self, '_cross_user_confirmed')` 를 0.1초 폴링으로 기다린다.
- 스케줄 등록: `App.create_scheduled_task` → `_save_schedule_config`(JSON) → `_create_task_xml` → `schtasks /create /xml`. 비frozen 이면 인자에 `os.path.abspath(__file__)` 를 넣는다.

### GUI 와 Headless 의 현재 동작 차이 (Q1 기준선)
| 항목 | GUI `run_backup` | Headless `core_run_backup` |
|---|---|---|
| `.` 시작 이름, thumbs.db·desktop.ini·$recycle.bin | 필터로만 제외 | 항상 숨김 처리 |
| AppData·Application Data·Local Settings 특수 규칙 | 적용 안 함(`is_hidden_safe`) | Hidden·System 둘 다 include 일 때만 포함 |
| pywin32 없을 때 속성 판정 | 건너뜀(숨김·재분석 지점 포함됨) | ctypes fallback |
| 여유 공간 사전 확인 | 함 | 안 함 |
| 작업 로그 문구 | `Backup start: …`, `Processing directory` 줄, 필터 제외도 `Skipping hidden` | `Backup start for '…' →`, `Skipping filtered …`, 일부 줄에 줄바꿈 누락(Q1 예외로 고친다, 0003 §6) |
| `--log-folder` | 해당 없음 | 받지만 쓰지 않는다(로그는 `dest` 에) |
| 복사 실패 파일 수 | 셈에 포함 | 제외 |

### 외부 I/O (현재 위치)
- 파일시스템: App·`core_run_backup` 곳곳에서 `os`·`shutil` 직접. 사용자 루트 `C:\Users` 하드코딩(두 경로 모두).
- subprocess: `schtasks`(등록·삭제), `pnputil`(Popen `shell=True`), `net use`(cp949), `winget`(Popen), `powershell` toast, `mmc devmgmt.msc`, 탐색기, WMI 조회 — 약 30곳.
- ctypes·pywin32·winreg: 파일 속성, `IsUserAnAdmin`, `ShellExecuteW runas`, 여유 공간, 레지스트리 BaseBoard.
- 시계: `datetime.now()` 를 이름·로그마다 직접 호출(함수 안 지역 import 포함).
- 환경 변수: `%APPDATA%\ezbak\settings.json`, `%APPDATA%\ezBAK\ezBAK_Schedule\*.json`, `%LOCALAPPDATA%` 북마크(실행 계정 기준).

### 데이터 형식 (C3 대상)
- settings.json: `hidden, system, retention_count, log_retention_days, sound_enabled, filters{include,exclude}, theme, language`. 읽을 때 필터 type 을 소문자로 정규화하고 `ext/name/path` 외는 버린다.
- 스케줄 JSON: `task_name, user, dest, schedule, time_str, monthly_day, include_hidden, include_system, retention_count, log_retention_days, filters, created_at`. Headless 는 필터를 정규화 없이 넘기지만 매칭·로그 출력에서 type 을 `.lower()` 한다.
- 백업 폴더 `<user>_backup_<YYYY-MM-DD_HHMMSS>`, 로그 `<user>_backup_<ts>.log`, 북마크 `Chrome_Bookmarks`·`Edge_Bookmarks` 는 dest 루트. 작업 로그 줄 형식 `[YYYY-MM-DD HH:MM:SS] <메시지>`.
